# Attribution

## Goal

This file describes how the original work should be credited.

## Non-commercial use

For personal, hobby, and educational use, attribution is strongly requested whenever practical.

Suggested credit text:

`Based on MSpa Smart Controller by André Hestnes`

If possible, also include:

- a link to the repository
- a note of any modifications you made

## Commercial or professional use

Commercial use should include attribution unless explicitly waived in writing in the commercial license agreement.

Recommended attribution text:

`Based on MSpa Smart Controller by André Hestnes. Used under commercial license.`

Where practical, attribution should appear in at least one of:

- product documentation
- project documentation
- installer or service documentation
- about page
- repository README
- release notes

## Modified versions

If you distribute modified versions, it is good practice to state:

- that the work is modified
- what you changed at a high level
- that the original project is by André Hestnes

Suggested form:

`Modified from MSpa Smart Controller by André Hestnes`
